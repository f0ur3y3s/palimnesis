# Papers

Papers motivate mechanisms; `docs/contracts.md` and protocol correctness prevail. A module implementing one of these names it in its docstring with any adaptation.

| Paper | Mechanism Palimnesis takes | Phase | Not taken / adapted |
| --- | --- | --- | --- |
| [ARC](https://arxiv.org/html/2607.25066v1) | Observation masking with exact addressable recall; bounded catalog pages; paired-outcome (McNemar) analysis | 2, 3, 7 (recall tools and model-facing catalog navigation: optional 3B, A1) | Active-view assumptions are checked against the proxy's budget contract, not adopted wholesale |
| [LCM](https://arxiv.org/html/2605.04050v1) | Immutable history; optional hierarchical summary DAG; escalation detailed → bullets → deterministic; memory tools | 1, 5 | "Zero-cost continuity" concerns short-task recursive overhead, not prefix-cache guarantees |
| [The Complexity Trap](https://arxiv.org/abs/2508.21433) | Deterministic masking is competitive with LLM summarization; scaffold-dependent evaluation | 2, 7 | — |
| [Eunoe](https://github.com/chroxify/eunoe) (MIT; software, not a paper) | Proactive recall: before each user message is answered, BM25 over archived content no longer in context, with matches quoted exactly in a delimited block appended to that user message, computed once and pinned so the prefix cache holds; readable per-session transcript files (`index.md` plus `turn-NNNN.md`) searched by the agent through a short recipe when recall misses | 2, 3 (A1) | **Evidence limits:** Claude Code with Anthropic models; ~110K-token prompts (the README's "prompt size when asked"); 24 held-out sessions of 90–120 turns from one developer; one run per arm; 600 planted facts scored by exact match; the answering model is unnamed; vague references are a stated weakness. It does not establish results at 32–64K with local models. **Adaptations:** budgets at 32–64K with per-message and total excerpt caps that may fall to zero; whole-block deterministic omission with recorded invalidations; a bounded, deterministic query construction instead of the raw message as query; search over every archived span absent from the resulting view, including user messages; Eunoe searches tool outputs no longer in context plus what the agent said while working; transcripts as a crash-safe, rebuildable projection of the immutable archive; a harness capability gate before claiming transcript fallback. **Not taken:** Eunoe's own context folding (a ~100K budget keeping the last 3 turns with verbatim evidence lines); its cache safety rests on changing the prefix only at a fold, which Palimnesis's threshold events (D20.1) mirror |
| [RaMem](https://arxiv.org/abs/2606.22844) | Contextual evidence (neighbors, provenance) and retrieval validity | 6 | Principles only; not its full long-term-memory framework |
